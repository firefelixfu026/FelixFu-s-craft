# 文档导航

这里整理项目的正式说明、部署手册、数据库说明和历史记录。为了方便验收和后续维护，常用文档都尽量使用中文标题和中文文件名。

## 当前主线

网站当前定位是“个人主页 + 随笔 / 娱乐文章 + 技术笔记知识库 + 音乐 + 暑期计划”。

- `随笔 / 娱乐文章`：放生活、游戏、番剧、读书和小作文。
- `技术笔记`：放课程笔记、项目文档、代码学习记录。阅读页采用可悬浮滑出的左侧笔记树、中间正文、右侧目录和阅读进度。
- 笔记收纳：后台可维护合集和目录路径，前台自动显示为可折叠目录树。
- 后台管理：保留写文章、笔记上传、内容库、评论删除、音乐管理、版本记录、运维和安全。
- 笔记上传：支持导入 `.md` 文件，也支持选择包含图片的笔记文件夹。
- 工具箱：支持管理员新增、编辑、删除自定义网址，并保存到后端数据库。
- 侧边栏：桌面端使用轻量展开/折叠动画，移动端保持稳定横向导航。

## 归档文档

历史推进记录、旧计划、临时清单和排查记录放在 `docs/archive/` 目录中。

这些文件主要用于追溯项目从 MVP 到正式上线的过程，正常验收和部署时不需要逐个阅读。

当前归档重点：

- `docs/archive/project-history/`：旧需求、代码分析、下一步计划和发布清单。
- `docs/archive/GITHUB_PUSH_TROUBLESHOOTING.md`：早期 GitHub 推送问题排查。
- `docs/archive/DOCKER_DESKTOP_SETUP.md`：早期本地 Docker 环境说明。
